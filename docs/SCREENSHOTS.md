# CrewFlow screenshots

The public gallery contains ten actual Chromium captures of CrewFlow using **temporary fictional API fixtures**. These images demonstrate presentation only, not real account sessions, backend authorization, database contents or persistence. No private credentials are included.

Desktop captures use a 1440 × 1000 viewport, with full-page captures where appropriate. The selected mobile image uses a 390 × 844 viewport. Broader desktop/tablet/mobile and light/dark inspections are described in the [verification summary](VERIFICATION.md). Diagnostic captures and upstream screenshots remain local and are excluded from the publication set.
